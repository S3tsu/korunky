# Korunky

Procvičování financí, ekonomie, práva a daní podle přednášek: lekce, studium s výběrem A–D, kartičky, příklady s náhodnými čísly a postupem, test nanečisto, přehled s tahákem k tisku a Herna. Maskot je křečice Kačka Křečková.

Web: https://s3tsu.github.io/korunky/

Bez buildu: `index.html` (vzhled a kostra), `app.js` (logika), `predmety/*.js` (obsah po předmětech), `sw.js` (offline), `manifest.webmanifest` a ikony (instalace na plochu). Pokrok se ukládá v prohlížeči (localStorage `kr-p`), přenést ho jde kódem zálohy `KR1-…`.

Spuštění lokálně: `python3 -m http.server` v téhle složce a otevřít `http://127.0.0.1:8000/`.
